# Le latin par les locutions

Un cours de latin bâti sur des locutions authentiques — maximes, proverbes,
citations — où chaque phrase sert à la fois d’exemple grammatical et de porte
d’entrée culturelle.

**L’application : [à compléter avec l’adresse GitHub Pages]**

## Le principe

Chaque unité enseigne un point de grammaire à partir d’une dizaine de citations
réelles, vérifiées sur le texte continu de leur auteur. L’étudiant devine le
sens, recompose la phrase, complète une forme manquante, cherche l’entrée du
dictionnaire, analyse chaque mot, et reconstitue le paradigme — puis découvre
d’où vient la phrase et ce que le français en a gardé.

Les sept premières unités couvrent les cinq déclinaisons. Les suivantes
aborderont les conjugaisons.

## Ce que l’application n’est pas

Elle ne collecte rien, n’exige aucun compte, ne dépend d’aucun serveur. C’est un
seul fichier HTML qu’on ouvre dans un navigateur. Seule une préférence
d’affichage — le mode « lecture facilitée » — est conservée dans le navigateur
de chacun.
